Cross APIs

SAES Cloud · api-auth · api-permissions · api-users

Todos los endpoints (excepto /login y /refresh) requieren Authorization: Bearer {access_token}.
Los endpoints marcados interno son llamados únicamente entre servicios y están bloqueados por el API gateway para clientes externos.
api-auth

Ciclo de vida de sesiones. Único servicio que conoce los hashes de contraseñas. Emite y revoca tokens opacos (32 bytes hex). Todos los demás servicios lo consultan vía /internal/tokens/validate.

POST /login Autenticar usuario. Emite access token (15 min) + refresh token (7 días). Rate limit: 5 req/min por IP, 10/min por identifier.
