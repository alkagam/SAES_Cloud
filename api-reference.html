Quickstart

Empieza a consumir la API en 3 pasos.

1

Inicia sesión

# POST /api/auth/login
curl -s -X POST ${API_BASE_URL}/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"identifier":"2023630001","password":"TuPassword"}'

# Respuesta:
{
  "access_token":  "0f7315de55b6c55c45d8d3c7...",
  "refresh_token": "1410928e5aaa52b378a489b5...",
  "expira_en":     900
}

identifier es la boleta para alumnos y el num_empleado para docentes. El access_token expira en 15 min; usa /api/auth/refresh para renovarlo.

2

Obtén tu identidad

# GET /api/users/me  — conoce tu id_alumno / id_docente
curl -s ${API_BASE_URL}/api/users/me \
  -H "Authorization: Bearer <access_token>"

# Respuesta:
{
  "id_usuario": 4,
  "rol":        "alumno",
  "id_alumno":  1,
  "id_docente": null
}

Necesitarás id_alumno para consultar grupos disponibles y calificaciones.

3

Consulta y opera

# Ejemplo alumno: ver grupos disponibles en el período activo
curl -s "${API_BASE_URL}/api/enrollments/groups/available?period=2025-1&student=1" \
  -H "Authorization: Bearer <access_token>"

# Inscribirse a un grupo
curl -s -X POST ${API_BASE_URL}/api/enrollments/enrollments \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"id_grupo":1,"tipo":"Ordinaria"}'

# Ejemplo docente: ver calificaciones de su grupo
curl -s ${API_BASE_URL}/api/grades/grades/groups/1 \
  -H "Authorization: Bearer <access_token>"

Roles y permisos

alumno
Inscribir/dar baja grupos · Ver calificaciones propias
docente
Capturar calificaciones · Ver lista de alumnos por grupo
dae
Crear alumnos/docentes · Crear materias · Cambiar carrera
gestion
Crear grupos/horarios · Asignar docentes · Iniciar semestre
root
Acceso total a todos los endpoints
Cross Autenticación /api/auth/  ·  :9001
POST /api/auth/login
Sin auth Rate limit 10/min

Autentica un usuario y devuelve access_token (15 min) y refresh_token (7 días).

Body
CampoTipoDescripción
identifierstringrequeridoBoleta (alumno) o num_empleado (docente)
passwordstringrequeridoContraseña en texto plano
Respuesta 200
{ "access_token": "...", "refresh_token": "...", "expira_en": 900 }

Bearer
